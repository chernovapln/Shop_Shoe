# Система оформления заказа обуви "Чудо Обувь"

## Описание
Приложение на WPF (C#) для автоматизации заказа обуви. 
База данных: MS SQL Server (Entity Framework Core).

## Функционал:
1. **Авторизация**: Вход по логину (без пароля).
2. **Каталог**: Вывод товаров, поиск, фильтрация по категориям, сортировка по цене.
3. **Скидки**: Автоматический расчет скидки 25% на товары без заказов в прошлом месяце.
4. **Роли**:
   - *Авторизованный пользователь*: просмотр каталога, оформление заказа.
   - *Менеджер*: просмотр всех заказов.
   - *Администратор*: создание/удаление заказов, изменение дат, удаление позиций.

## Инструкция по запуску:
1. Восстановить базу данных из скрипта `DatabaseScript.sql`.
2. В файле `AppDbContext.cs` указать свою строку подключения к SQL Server.
3. Запустить проект в Visual Studio (F5).
